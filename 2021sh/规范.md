# 讲题视频 · 数学公式口径规范

适用于本项目所有讲题视频的画面文字、动画代码（Remotion 等）和配套脚本。

## 1. 总原则：所有数学内容一律用 LaTeX 书写，由 KaTeX 渲染

凡是变量、表达式、分式、根号、角度、希腊字母、集合符号、上下标、逻辑箭头，**哪怕只有一个字母**，都必须写成 LaTeX，不允许用 Unicode 字符直接拼。

| 禁止写法（纯文本） | 必须写法（LaTeX） |
|---|---|
| `√3/2`、`√3⁄2` | `\dfrac{\sqrt{3}}{2}` |
| `π/6`、`2π/q` | `\dfrac{\pi}{6}`、`\dfrac{2\pi}{q}` |
| `θ`、`φ` | `\theta`、`\varphi` |
| `P₁`、`x²` | `P_1`、`x^2` |
| `60°` | `60^\circ` |
| `⟹`、`⟺` | `\Rightarrow`、`\Leftrightarrow` |
| `≤`、`≥` | `\leqslant`、`\geqslant` |
| `n ∈ N*` | `n\in\mathbf{N}^*` |
| `2π · 2/5` | `2\pi\cdot\dfrac{2}{5}` |

## 2. 书写约定（与人教版、沪教版教材一致）

- **分式**：画面中一律用 `\dfrac`，正文行内也是，保证分式大小清晰，不用 `\frac` 或 `/`。
- **不等号**：用 `\leqslant`、`\geqslant`（斜杠型 ⩽ ⩾），不用 `\le`、`\ge`。
- **φ**：用 `\varphi`（教材写法），不用 `\phi`。
- **数集**：`\mathbf{N}^*`、`\mathbf{R}`、`\mathbf{Z}`。
- **区间**：用 `\left[ … \right]` 自动撑高，例如 `\left[-\dfrac{\pi}{6},\dfrac{\pi}{6}\right]`。
- **三角函数**：用 `\cos`、`\sin`、`\tan`（直立体），不写成斜体的 cos。
- **乘号**：数与字母相乘用 `\cdot`；需要突出乘法时才用 `\times`。
- **近似**：用 `\approx`，小数保留 3 位。
- **公式里夹中文**：用 `\text{…}`，例如 `\text{间隙 }\dfrac{2\pi}{q}=72^\circ`。
- **标点**：中文句子里用全角标点（，。：），公式内部用半角。

## 3. 代码实现要求（Remotion）

- **HTML 文字中的公式**：用 `` M`…` `` 模板标签，或 `<Tex tex="…" />`。
  例：`` 已知 {M`\theta>0`}，求 {M`\theta`} 的最小值 ``
- **SVG 画面里的公式标签**：用 `<TexLabel x y tex="…" />`（内部通过 `foreignObject` 渲染），不用 `<text>`。
- **动态数值**：用模板插值，例如 `` M`\cos x=${v.toFixed(3)}` ``。
- **字体**：KaTeX 必须引入 `katex/dist/katex.min.css`，否则分式和根号会变形。
- **配色**：给整段公式着色时，在外层 `span` 上设 `color`，不要在 LaTeX 里写 `\color`。

## 4. 排版检查

- 包含 `\dfrac` 的行，行距至少要能容下一个分式的高度（字号 44 时约 110px）。新增或修改文字后，至少渲染一帧确认没有重叠。
- 表格里分式和非分式混排时，每一行用固定行高并垂直居中（`display:flex; align-items:center`）。

## 5. 自动校验

工程里提供了 `npm run check`（`scripts/check-math.mjs`）：
源码字符串中一旦出现 `√ π θ φ ⁄ ₁ ⟹ ≤ ° ·` 等 Unicode 数学字符，或 `2/5` 这类斜杠分式，就会报错并列出行号。
`npm run build` 会先跑这项检查，**不通过不出片**。

## 6. 配套文字脚本（旁白稿、分镜稿）

分镜的「画面」栏中，需要显示在屏幕上的公式同样用 LaTeX 标注（写在 `$…$` 里），方便直接复制进代码。
「旁白」栏是给人读的，用口语表达，例如"二分之根号三""三分之派"，不写符号。
